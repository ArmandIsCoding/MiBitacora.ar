# Mi Bitácora

Al terminar una funcionalidad, verificá el cambio, creá un commit y subilo a la rama correspondiente del repositorio de GitHub. Confirmá que el commit llegó al remoto. Incluí los archivos y la documentación de la funcionalidad, y preservá los cambios locales ajenos al trabajo.

El repositorio de GitHub es público. Nunca versiones credenciales, contraseñas, tokens, claves de firma o de sesión, configuraciones privadas, bases, respaldos ni contenido real de los diarios. Revisá también capturas, ejemplos y archivos generados antes de agregarlos. Usá datos sintéticos para las pruebas y mantené los archivos privados fuera de Git y de la publicación web.

La ubicación comercial pública autorizada es únicamente «(3000) Santa Fe, Argentina». No publiques calle ni altura del domicilio particular en código, páginas, correos, documentación o capturas.

Después de limpiar datos privados del historial, partí de la rama remota actual y no vuelvas a fusionar ni subir los commits anteriores que contenían esos datos.
